# ZAN-G clothing store — starter prototype

## Run it
1. Download and unzip `zan-g-store.zip`.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. No build tools or paid software are required.

## What's included
- Responsive ZAN-G landing page in black, white and red.
- Namaste welcome area and Get Started button.
- Auto-changing hero clothing showcase (CSS mockups, not real product photos).
- Category filters and demo product cards.
- Demo shopping bag counter.
- Mobile/Gmail sign-in preview modals.

## Important limitations
This is a front-end prototype only. It does **not** authenticate users, accept payments, create real orders, or connect to a POD provider. Do not collect customer phone numbers or payment details in this static version. Real mobile OTP / Google sign-in needs a secure authentication provider and backend configuration. Real checkout and POD fulfilment need a supplier integration and a tested payment/order workflow. Since the owner is under 18, a parent/guardian should manage any business accounts, payment setup and agreements.

## Add your own designs
The current clothing artwork is made with CSS placeholders. Replace the `.model` and `.category-art` mockups with product photos/mockups of your own designs. Keep image files in an `images/` folder and use paths such as `images/my-design-front.png` in `index.html` or CSS.

## Free hosting
You can publish this static site with GitHub Pages from a public repository. A custom domain is optional and usually costs money.
