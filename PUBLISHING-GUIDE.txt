ZAN-G — FREE PUBLISHING GUIDE

The website is a static front-end prototype. You can host it on GitHub Pages at no hosting cost using a public repository.

BEFORE PUBLISHING
1. Create or sign in to GitHub (ask a parent/guardian to help manage the account and business details).
2. Create a new PUBLIC repository named zan-g-store.
3. Upload index.html, style.css, script.js, and logo.svg from this folder.
4. Open the repository Settings.
5. Select Pages from the left menu.
6. Under Build and deployment, choose Deploy from a branch.
7. Select the main branch and /(root), then Save.
8. Wait for GitHub Pages to publish. The website URL will appear in Settings > Pages.

IMPORTANT
- Do not upload passwords, API keys, private customer data, or payment secrets into this public repository.
- A public GitHub Pages site is a static website. It cannot securely process OTP login, Google OAuth secrets, payments, or private orders by itself.
- The current sign-in prompts are demo placeholders. No phone number, Gmail address, password, or payment data is collected.
- The product photos in this first prototype are CSS mockups. Replace them with your own original design photos/mockups before selling.
- Real POD fulfilment requires a supplier account, tested order integration, and a safe payment arrangement. Production and shipping costs still have to be paid.
- Because the brand owner is under 18, a parent/guardian should manage business registrations, payment accounts, contracts and supplier accounts.
